# Design System — cloudfile

Generated by /design-consultation on 2026-04-23
方向：**Warm Scholar（温暖学者）**

> ⚠️ 本文档是 cloudfile **视觉设计系统**的源头。代码里任何颜色值、字号、间距都必须走这里定义的 CSS 变量——**不得硬编码**。`DESIGN.md` 是产品设计文档（Problem/Approach/架构），本文档是视觉层规范，两者各司其职。

---

## Product Context

- **What this is**: 自托管 AI-first 云文档系统
- **Who it's for**: 自己 + ≤10 人小团队，在自己服务器上写私人笔记
- **Space**: 云文档 / AI 协作工具
- **Project type**: **App UI**（不是 marketing site——无公开注册，无 hero）
- **Reference products**: Craft、iA Writer、Bear（暖调纸感）+ Linear、Obsidian（工具性）

## Aesthetic Direction

- **方向**: Editorial/Minimal——字体做主角，留白做舞台
- **装饰级别**: Minimal + 极轻微 grain（可选，避免 flat SaaS 廉价感）
- **Mood**: "这是我的数字书房"。皮面笔记本的温度 + AI 时代的工具性。用户打开 cloudfile 时应该感到**属于自己**，而不是"又一个 SaaS 工具"
- **一句话视觉论点**: 大部分云文档是冷色蓝紫（Notion/飞书/Linear），cloudfile 走暖色琥珀+卡其白——在视觉上一眼和所有对手区分

## Typography

### 字体栈

| 角色 | 字体 | Fallback |
|---|---|---|
| **Display/Heading** | `'DM Sans'` | `'Noto Sans SC', -apple-system, sans-serif` |
| **Body/UI** | `'DM Sans'` | `'Noto Sans SC', -apple-system, sans-serif` |
| **Serif**（blockquote、引用、首段点缀） | `'Newsreader'` | `Georgia, serif` |
| **Mono/Code/Timestamp** | `'JetBrains Mono'` | `'Courier New', monospace` |

**加载策略**（生产环境）：从 Bunny Fonts（GDPR 友好，国内访问稳）按需加载；开发期可用 Google Fonts。

```html
<link rel="stylesheet" href="https://fonts.bunny.net/css?family=dm-sans:400,500,700|newsreader:400i|jetbrains-mono:400,500&display=swap">
```

**Noto Sans SC** 从 fontsource 或 CDN 按需加载（中文场景）。

### 字号阶梯（1.25 倍）

| Token | px | rem | 用途 |
|---|---|---|---|
| `--text-xs` | 12 | 0.75 | 时间戳、meta 信息、标签 |
| `--text-sm` | 14 | 0.875 | 侧边栏、按钮、表单标签 |
| `--text-base` | 16 | 1 | 正文 |
| `--text-lg` | 20 | 1.25 | h3 / 卡片标题 |
| `--text-xl` | 25 | 1.5625 | h2 / 页面副标题 |
| `--text-2xl` | 31 | 1.9375 | h1 / 页面主标题 |
| `--text-3xl` | 39 | 2.4375 | 编辑器文档大标题（hero） |

### 行高

| Token | 值 | 用途 |
|---|---|---|
| `--lh-tight` | 1.2 | 标题 |
| `--lh-normal` | 1.5 | UI 正文 |
| `--lh-relaxed` | 1.75 | 长文阅读（编辑器） |

### 字重

- 400（常规）— body、UI
- 500（中等）— 标题 h3、按钮
- 700（粗）— 标题 h1/h2、强调

### 对比度

所有文字/背景组合 **≥ 4.5:1**（WCAG AA 正文）；UI 组件边界 **≥ 3:1**。

- `--text-primary` on `--bg-primary`: 14.8:1 ✅
- `--accent` on `--bg-primary`: 4.9:1 ✅（prose 使用 OK）
- `--text-tertiary` on `--bg-primary`: 3.1:1 ⚠️（仅 meta 信息；不可用于正文）

## Spacing

**基准单位：4px**。密度：`comfortable`（App UI 需要密度，但给长文阅读留呼吸）。

| Token | px | 用途 |
|---|---|---|
| `--space-2xs` | 2 | 图标内距、tabular-num 字距 |
| `--space-xs` | 4 | icon + text 间距、紧凑容器 |
| `--space-sm` | 8 | 按钮内 padding-y、列表项间隔 |
| `--space-md` | 16 | 默认 padding、卡片内边距 |
| `--space-lg` | 24 | 段落间距、section 内边距 |
| `--space-xl` | 32 | section 之间、页面大内边距 |
| `--space-2xl` | 48 | 页面顶部 padding、英雄区 |
| `--space-3xl` | 64 | 极少用——编辑器最大内边距 |

## Layout

- **布局方式**: grid-disciplined（严格网格——App UI 不搞 editorial 斜线/重叠）
- **主 grid**: 12 列，gutter 24px，容器最大 1280px
- **编辑器最大宽度**: **720px**（长文阅读最佳行宽 60-75 字符）
- **侧边栏固定宽度**: 240px
- **断点**: 只定义 `--bp-desktop: 1024px`，< 1024px 显示"推荐桌面访问"提示页

### 圆角

| Token | px | 用途 |
|---|---|---|
| `--radius-sm` | 4 | 输入框、小按钮 |
| `--radius-md` | 6 | 卡片、面板、modal 内的区块 |
| `--radius-lg` | 10 | modal、弹出面板 |
| `--radius-full` | 9999 | badge、chip、头像 |

**不使用**：大圆角（> 12px，AI slop bubbly）；uniform 超大圆角。

### 阴影

克制使用。Warm Scholar 不用 shadow 做主要层级区分，**用 border + 背景差**代替。

```css
--shadow-sm: 0 1px 2px rgba(28, 25, 23, 0.04);  /* 仅浮层 */
--shadow-md: 0 4px 12px rgba(28, 25, 23, 0.08); /* modal、dropdown */
```

## Motion

**方向**: `minimal-functional`——只服务于状态变化；不做装饰性动画。

### Duration tokens

| Token | ms | 用途 |
|---|---|---|
| `--dur-micro` | 80 | hover 色变、focus ring |
| `--dur-short` | 200 | panel 展开、tooltip |
| `--dur-medium` | 350 | modal 打开、页面切换 |
| `--dur-long` | 600 | 仅 page transition（极少用）|

### Easing

```css
--ease-out: cubic-bezier(0.16, 1, 0.3, 1);       /* 默认进入 */
--ease-in-out: cubic-bezier(0.4, 0, 0.2, 1);    /* 双向过渡 */
--ease-in: cubic-bezier(0.4, 0, 1, 1);          /* 退出 */
```

**不做**：scroll-linked animation、parallax、自动轮播、弹簧 bounce。

### AI Activity 时间线项（"像日志，不是消息通知"）

等宽字体时间戳 + 琥珀 accent + 左侧竖向时间轴线。

```
10:32  ● Claude(alice) 修改了 Project X    +12 -3    [diff]
09:15  ● Claude(alice) 创建了 Q1 总结                 [打开]
```

时间戳 `JetBrains Mono`；item 文字 `DM Sans`；修改量 `JetBrains Mono` tabular-nums。

## 品味校准（taste calibration）

这套设计系统是基于这些作为**品味参照**的：

**值得学**：
- Craft 的**留白 + 温度**（但 cloudfile 更 utility）
- Linear 的**克制 + 一致性**（但 cloudfile 是暖调）
- iA Writer 的**字体尊重**（让文字做主角）
- Obsidian 的**无干扰**（但 cloudfile 有 AI 可视化）

**绝对不做**：
- 紫色/蓝紫渐变（AI slop #1）
- 3 列图标圆圈 feature grid（AI slop #2）
- 居中一切 + 通用 SaaS hero
- 装饰性 blob / wavy divider
- Emoji 做设计元素（头部标题用 emoji 不可接受）
- 颜色-左边框卡片（`border-left: 3px solid <accent>` 这种 SaaS 模板专属）
- 大圆角 bubbly 风

## 实施约束

1. **所有颜色必须走 CSS 变量**——代码里不允许出现 `#D97706` 等字面色值（linter 规则）
2. **所有间距必须走 `--space-*`**——不允许 `padding: 13px 27px` 这种"眼睛拍脑袋"数值
3. **圆角必须走 `--radius-*`**——不允许 `border-radius: 15px` 等随机值
4. **字号必须走 `--text-*`**——不允许 `font-size: 17px` 等随机值
5. **所有字体都要有中文 fallback（Noto Sans SC）**——产品主要用户在中国
6. **暗色模式默认不开启**——用户点击主题切换才启用；系统暗色不自动跟随（避免 Milkdown 主题抖动）
7. **CSS 变量定义集中在 `frontend/src/styles/tokens.css`**——所有其他 CSS 文件只消费变量
