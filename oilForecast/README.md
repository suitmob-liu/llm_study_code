# 皖 · 安徽油价预测系统

独立子项目，Python + FastAPI + SQLite + 原生网页，无前端构建。记录安徽省 92/95/98 号汽油、0 号柴油历史最高零售价格，结合 Brent/WTI 与美元兑人民币行情，估算下次调价的每吨调幅、各标号每升价格。

## 启动

```powershell
cd oilForecast
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt
.venv/Scripts/python -m uvicorn app.main:app --host 127.0.0.1 --port 8787
```

打开 http://127.0.0.1:8787 。Linux/macOS 将 `.venv/Scripts/python` 替换为 `.venv/bin/python`。

Docker：`docker compose up -d --build`，默认绑定本机 8787 端口，数据持久化在 `oil-data` 卷。项目为私人本机工作台，无登录；需要多人/公网使用时，应置于提供身份认证和 HTTPS 的反向代理之后。

## 使用

1. 「安徽油价档案」录入已生效的油价及安徽省发改委公告来源。若公告为某日 24 时调价，生效日期填写次日。历史按日期倒序，并显示 92 号较上次的变化。
2. 「国际原油行情」录入每日 Brent、WTI 收盘价和当日美元兑人民币。保持报价合约、币种及时间口径一致，每个交易日一条。来源可记录行情提供方与合约名称。同日保存修正旧值。
3. 「调价推演」指定完整基期、本期开始、观察截止与下次调价日期。默认周期十个交易日，支持缩短以研究情景。基期记录数必须等于设定周期天数，本期至少一条且不超过该数。系统不会把周末、节假日或未发布行情自动补成观测值；交易日与调价日期由用户按官方日历确定。
4. 若本期未走完，剩余各日价格 = 最新已录原油价格 × (1 + 情景涨跌幅)，汇率维持最新值。滑块改变后点击重新计算。完整本期行情下滑块不改变结果。
5. 支持导出两类 CSV；原始数据保存在 `data/oil.sqlite3`，重启不丢失。`OIL_DB_PATH` 可更改数据库位置，备份时停服复制该文件。

系统不预装未经核验的历史价格，也不自动抓取实时行情。「填入演示参数」只填入示例日期，不保存假油价或假行情；这些日期不代表官方窗口。CSV 是导出备份，暂不提供批量导入。

## 模型与局限

- 代理原油篮子：Brent × 权重 + WTI × (1 − 权重)，默认各 50%。使用每日汇率折算人民币/桶，然后比较两周期均价。
- 预计每吨调幅 = 两期人民币/桶均价之差 × 7.33 桶/吨 × 传导系数（默认 0.6）+ 手动录入的上期结转。传导系数为可调经验参数，未经过历史回测标定。
- 绝对调幅不足 50 元/吨暂缓调整，返回参考结转，**不自动累积**；下一周期由用户核验后填写，避免重复计算。
- 近似地板价处理：每日代理篮子不低于 40 美元参与计算；基期或预计本期均价高于 130 美元时停止输出具体价格。此逻辑不能复现特殊政策下的官方处理。
- 吨转升系数：92# 0.00075、95# 0.00079、98# 0.00083、0# 0.00086。人民币每升按四舍五入保留两位。系数为估算密度换算，实际各标号官方调整幅度可能不同。
- 预测使用本期开始时最近一条已生效油价，避免后续录入的调价记录污染历史周期推演。
- 官方使用的原油篮子、加工成本、税费、政策调控并未公开完整复现；结果是可解释的情景估算，**不是官方预测或实际执行价格**。不提供缺乏统计依据的「准确率」或置信区间。

## 验证

```bash
python -m unittest discover -s tests -v
node --check static/app.js
```

覆盖涨跌与精确金额、50 元门槛与结转、汇率、剩余交易日情景、地板/高价边界、数据不足与非法输入、历史时点选价、同日修正、重启持久化、CSV 公式转义、API 与静态资源。

接口文档：http://127.0.0.1:8787/docs 。`GET /api/data` 查询历史，`POST /api/retail` 保存油价，`POST /api/quotes` 保存行情，`POST /api/forecast` 推演，`GET /api/export/retail` 和 `/api/export/quotes` 导出。
