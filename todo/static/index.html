配置教程

完全免费 · 2000条/天
1
获取 appToken

打开 wxpusher.zjiecode.com/admin，用微信扫码登录

进入后点击左侧「应用管理」→「新建应用」→ 填写应用名称（如"我的待办"）→ 创建后复制 appToken

2
获取 UID

微信关注公众号 「wxpusher」

进入公众号 → 点击底部菜单「我的」→「我的UID」→ 复制 UID

3
关注应用

回到 WxPusher 管理后台 → 点击你创建的应用 → 「应用二维码」

用微信扫码关注该应用（这一步是让你的微信能收到这个应用的推送）

4
填入 Token

在上方输入框填入，格式：

你的appToken|你的UID

中间用英文竖线 | 分隔，然后点「保存设置」

5
测试

保存后点击上方「立即发送」按钮，微信应收到待办提醒消息

免费版有限额 · 200条/天
1
关注公众号

微信搜索并关注公众号 「pushplus」

2
获取 Token

打开 pushplus.plus → 微信扫码登录 → 首页即可看到你的 token，复制即可

3
填入并测试

粘贴 token 到上方输入框 → 保存设置 → 点击「立即发送」测试

免费版 · 5条/天
1
登录绑定

用 GitHub 账号登录 sct.ftqq.com → 微信扫码绑定

2
获取 SendKey

登录后在「Key & API」页面复制 SendKey

3
填入并测试

粘贴 SendKey 到上方输入框 → 保存设置 → 点击「立即发送」测试

仅推送到企业微信群
1
创建群机器人

打开企业微信 → 进入目标群聊 → 右上角设置 → 「群机器人」→「添加」

2
复制 Webhook URL

创建后复制完整的 Webhook 地址

https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxx
3
填入并测试

粘贴完整 URL 到上方输入框 → 保存设置 → 点击「立即发送」测试
